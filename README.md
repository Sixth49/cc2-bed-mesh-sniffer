# Elegoo Centauri Carbon 2 (CC2) Bed Mesh Sniffer & 3D Visualizer

Набор инструментов для перехвата MQTT-трафика 3D-принтера **Elegoo Centauri Carbon 2** во время автокалибровки стола (Auto Bed Leveling) и построения интерактивной 3D-карты высот.

Поскольку CC2 не отдает готовую сетку высот одним сообщением, этот проект перехватывает инкрементальные обновления координат (`gcode_move.x/y/z`) по MQTT, реконструирует траекторию движения каретки и фильтрует высоты контакта с столом, восстанавливая полную сетку (обычно 11x11 точек).

##  Возможности
* **Сниффер трафика (`cc2_mesh_sniffer.py`)**: подключается к встроенному MQTT-брокеру принтера, логирует весь трафик и сохраняет сырой дамп.
* **Реконструктор сетки (`cc2_bed_mesh_3d.py`)**: анализирует дамп, автоматически находит фазу калибровки, отсеивает холостые перемещения и строит точную карту высот.
* **Интерактивная 3D-визуализация**: генерирует HTML-файл с графиком Plotly, который можно вращать и масштабировать в браузере.
* **Экспорт данных**: сохранение сетки в `.csv` и тепловой карты в `.png`.

##  Требования
* Python 3.x
* Принтер и ПК должны быть в одной локальной сети.
* На принтере должен быть включен **LAN-режим** (Settings → Network → LAN Only Mode).
