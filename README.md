## 📖 О проекте

Штатный интерфейс **Elegoo Centauri Carbon 2** не отдаёт готовую сетку высот одним сообщением. Во время автокалибровки (Auto Bed Leveling) принтер лишь потоком шлёт инкрементальные обновления координат `gcode_move.x/y/z` по MQTT.

Этот проект:
1. **Перехватывает** весь MQTT-трафик принтера во время калибровки.
2. **Реконструирует** траекторию движения каретки из дельт координат.
3. **Фильтрует** холостые перемещения (ретракты, парковки) и оставляет только моменты касания стола.
4. **Восстанавливает** полную сетку высот (обычно **11×11 = 121 точка** на стоковом железе).
5. **Строит** красивую 2D-тепловую карту и интерактивную 3D-поверхность.

## ✨ Возможности

| Скрипт | Что делает |
|---|---|
| 🔍 `cc2_mesh_sniffer.py` | Подключается к встроенному MQTT-брокеру принтера, логирует весь трафик и сохраняет сырой дамп |
| 📐 `cc2_bed_mesh_3d.py` | Анализирует дамп, автоматически находит фазу калибровки, отсеивает шум и строит точную карту высот |
| 🌐 Интерактивная 3D-визуализация | Генерирует HTML-файл с графиком Plotly — можно вращать, зумить и панорамировать прямо в браузере |
| 💾 Экспорт данных | Сохранение сетки в `.csv` и тепловой карты в `.png` |

## ⚙️ Требования

- 🐍 **Python 3.8+** ([скачать](https://www.python.org/downloads/))
- 🌐 Принтер и ПК должны быть в **одной локальной сети**
- 📶 На принтере должен быть включён **LAN-режим**  
  `Settings → Network → LAN Only Mode → ON`
