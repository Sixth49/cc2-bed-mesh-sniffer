## 📖 О проекте

Штатный интерфейс **Elegoo Centauri Carbon 2** не отдаёт готовую сетку высот одним сообщением. Во время автокалибровки (Auto Bed Leveling) принтер лишь потоком шлёт инкрементальные обновления координат `gcode_move.x/y/z` по MQTT.

Этот проект:
1. **Перехватывает** весь MQTT-трафик принтера во время калибровки.
2. **Реконструирует** траекторию движения каретки из дельт координат.
3. **Фильтрует** холостые перемещения (ретракты, парковки) и оставляет только моменты касания стола.
4. **Восстанавливает** полную сетку высот (обычно **11×11 = 121 точка** на стоковом железе).
5. **Строит**  2D-тепловую карту и интерактивную 3D-поверхность.

## ✨ Возможности

| Скрипт | Что делает |
|---|---|
| 🔍 `cc2_mesh_sniffer.py` | Подключается к встроенному MQTT-брокеру принтера, логирует весь трафик и сохраняет сырой дамп |
| 📐 `cc2_bed_mesh_3d.py` | Анализирует дамп, автоматически находит фазу калибровки, отсеивает шум и строит точную карту высот |
| 🌐 Интерактивная 3D-визуализация | Генерирует HTML-файл с графиком Plotly — можно вращать, зумить и панорамировать прямо в браузере |
| 💾 Экспорт данных | Сохранение сетки в `.csv` и тепловой карты в `.png` |

## ⚙️ Требования

- 🐍 **Python 3.8+** ([скачать](https://www.python.org/downloads/))
- 🌐 Принтер и ПК должны быть в **одной локальной сети**
- 📶 На принтере должен быть включён **LAN-режим**  
  `Settings → Network → LAN Only Mode → ON`

## 📦 Установка

### 1. Скачайте скрипты

Сохраните оба файла в одну папку:
- `cc2_mesh_sniffer.py`
- `cc2_bed_mesh_3d.py`

### 2. Установите зависимости

Откройте терминал (PowerShell / Bash) и выполните:

```bash
pip install paho-mqtt matplotlib numpy
```
### 3. Скачайте скрипты

Сохраните оба файла в одну папку:
- 🔍 `cc2_mesh_sniffer.py` — подключается к принтеру и записывает весь MQTT-трафик в файл
- 📐 `cc2_bed_mesh_3d.py` — вытаскивает из этого файла карту высот и строит 3D-график

### 4. Запустите захват трафика

Перейдите в папку со скриптами. В Windows: `Shift + ПКМ` в папке → *«Открыть в терминале»*. или     `cd "C:\Users\......`

Запустите сниффер (подставьте свои IP и код доступа):

```bash
python cc2_mesh_sniffer.py --host "IP_ПРИНТЕРА" --password "КОД_ДОСТУПА"
```
пример `python cc2_mesh_sniffer.py --host 192.168.1.50 --password 123456`

**Не закрывайте терминал!** Пока скрипт работает и пишет сообщения в консоль:

1. На экране принтера откройте **Settings → Auto Bed Leveling**, **Настройки → Автокалибровка стола**
2. Запустите калибровку
3. Дождитесь её **полного** завершения
4. В окне терминала нажмите `Ctrl + C`, чтобы остановить скрипт

В папке со скриптами появится файл **`cc2_raw_dump.jsonl`** — сырой лог со всеми данными калибровки.

---

### 5. Постройте 3D-карту стола

В том же терминале выполните:

```bash
python cc2_bed_mesh_3d.py cc2_raw_dump.jsonl
```
Скрипт сам найдёт нужную фазу калибровки в логе и создаст в папке:

| Файл | Описание |
|---|---|
| 🗺️ `mesh_heatmap.png` | 2D тепловая карта с подписями значений высот |
| 📊 `mesh_grid.csv` | Сетка значений в виде таблицы (удобно для импорта) |
| 🌐 `mesh_3d_interactive.html` | Интерактивная 3D-карта — откройте в браузере, чтобы вращать и зумить |
